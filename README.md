FEU Roosevelt OJT Job Portal

A Web-Based Information System Offering Reliable Job Opportunities for OJT Students

📌 Project Overview

The FEU Roosevelt OJT Job Portal is a capstone project designed to help students find reliable and verified On-the-Job Training (OJT) opportunities through a centralized web-based platform.
The system connects students, administrators, and partner companies to streamline the internship application process, improve communication, and provide a more organized experience for both applicants and employers.
This project was developed as part of the academic requirements for the Information Technology program of FEU Roosevelt.

🎯 Objectives
Provide students with reliable and accessible OJT job listings
Help companies post internship opportunities efficiently
Allow administrators to manage student applications and company postings
Reduce fake or unverified internship offers
Improve the OJT application and monitoring process

🚀 Installation Guide
1. Clone the Repository
git clone https://github.com/yourusername/your-repository-name.git
2. Move Project Folder

Place the project folder inside the htdocs directory of XAMPP.

Example:

C:\xampp\htdocs\
3. Start Apache and MySQL

Open XAMPP Control Panel and start:

Apache
MySQL
4. Import Database
Open phpMyAdmin
Create a new database
Import the provided .sql file
5. Configure Database Connection

Update the database credentials inside:

config.php

Example:

$host = "localhost";
$user = "root";
$password = "";
$database = "ojt_portal";
6. Run the System

Open your browser and visit:

http://localhost/your-project-folder
